## 2. Descripción del Propósito de la Aplicación
Aplicación de escritorio desarrollada en Python utilizando `tkinter` y `ttk` que transforma el análisis espacial previo en una interfaz gráfica interactiva. Permite ingresar coordenadas en grados decimales, valida entradas no numéricas y rangos terrestres mediante ventanas emergentes, y calcula la distancia geodésica por Haversine junto con su dirección y clasificación[cite: 20, 22, 23, 24].
